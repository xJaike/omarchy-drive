### Maintainer notes

Plugin ID: `io.github.xjaike.omarchy-drive`

Google Drive sync status for the Omarchy bar, with full offline copies,
transfer percentages, speed, file counts, active filenames, and a live terminal
dashboard. Includes optional user-level setup and removal helpers for scheduled
two-way rclone bisync. Local files and credentials are retained on removal.

Requires Python 3, rclone, util-linux, and systemd user services. Initial release
syncs `~/GoogleDrive` with the `Omarchy` folder using an `omarchy-drive` rclone
remote. The repository includes setup instructions, an MIT license, and tests.
